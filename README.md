## About This Repository

This repository powered the original OWASP project page and contains historical releases, translations, working files, and supporting materials for the OWASP Top 10 for Large Language Model Applications.

It remains available so existing links, citations, and historical artifacts continue to work. New issues, pull requests, and release work should be directed to the [active repository](https://github.com/GenAI-Security-Project/GenAI-LLM-Top10).

The Top 10 is now a core initiative within the broader [OWASP GenAI Security Project](https://genai.owasp.org/), which develops freely available guidance and resources for securing generative AI systems and applications.
